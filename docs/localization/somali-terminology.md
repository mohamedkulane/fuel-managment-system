# Somali Business Terminology Glossary

> Central reference dictionary for Somali language localization in the Fuel Wholesale Management System.

| English Term | Standard Somali Translation | Context & Usage |
| :--- | :--- | :--- |
| **Dashboard** | **Guudmar** | Primary operational overview screen |
| **Customers** | **Macaamiisha** | Directory of wholesale customers |
| **Customer** | **Macmiil** | Individual customer entity |
| **Orders** | **Dalabyada** | Sales order registry |
| **New Order** | **Dalab Cusub** | Order creation flow |
| **Fuel Inventory** | **Kaydka Shidaalka** | Stock level management |
| **Stock Receiving** | **Shidaal Soo Gelin** | Inbound fuel stock receiving from suppliers/receiving |
| **Diesel** | **Naafto** | Fuel type code: DIESEL |
| **Petrol** | **Basiin** | Fuel type code: PETROL |
| **Fuel Pricing** | **Qiimaha Shidaalka** | Master selling rates per container unit |
| **Unit Price** | **Qiimaha Fuustadii** | Agreed price per Fuusto container |
| **Quantity** | **Tirada Fuustooyinka** | Container quantity in Fuusto units |
| **Invoices** | **Biilasha** | Billing following accepted delivered fuel |
| **Payments** | **Lacag-bixinnada** | Payment collection and receipt registry |
| **Outstanding Debt** | **Deynta Harsan** | Total unpaid invoice balance |
| **Customer Ledger** | **Diiwaanka Xisaabta Macmiilka** | Chronological customer financial subledger |
| **Account Statement** | **Warbixinta Xisaabta Macmiilka** | Official customer account statement |
| **Fixed Discount** | **Lacag-dhimis** | Fixed order-level dollar discount |
| **Subtotal** | **Wadarta Ka Hor Dhimista** | Order or invoice subtotal before discount |
| **Grand Total** | **Wadarta La Bixinayo** | Final net invoice or order amount |
| **Reports** | **Warbixinnada** | Business insights and export hub |
| **Settings** | **Dejinta** | Workspace configuration and user access |
| **Stock Movements** | **Dhaqdhaqaaqa Kaydka** | Audit log of inventory delta events |
| **Deliveries** | **Gaarsiinta Shidaalka** | Delivery lists and manifest preparation |
| **Dispatches** | **Shidaal Dirid** | Physical dispatch of fuel stock |
| **Delivery Reconciliation**| **Dib-u-heshiisiinta Gaarsiinta** | Actual delivery acceptance & physical return reconciliation |
| **Print** | **Daabac** | Print action |
| **Download PDF** | **Soo Dejiso PDF** | PDF download action |
| **Export Excel** | **Soo Dejiso Excel** | Excel export action |
| **Save** | **Kaydi** | Form submission action |
| **Cancel** | **Ka Noqo** | Modal/form cancel action |
| **Edit** | **Wax Ka Beddel** | Edit action |
| **Delete** | **Tirtir** | Removal action |
| **Search** | **Raadi / Kala Shaandhee** | Search or filter input placeholder |
| **Filter** | **Kala Shaandhee** | Filter control |
| **Status** | **Xaaladda** | Lifecycle status badge header |
| **Date** | **Taariikhda** | Date display |
| **Amount** | **Lacagta / Qadarka** | Monetary or numerical quantity |
| **Total** | **Wadarta** | Total calculation |
| **Details** | **Faahfaahin** | Detail view link or heading |
| **History** | **Taariikhda Hawlaha** | Audit log or historical record |
| **Owner** | **Milkiilaha** | Role: OWNER |
| **Office Employee** | **Shaqaalaha Xafiiska** | Role: OFFICE_EMPLOYEE |
